# Turtleler Sim

A fork of [https://github.com/ros/ros_tutorials](turtlesim) that introduces more advanced robotic features. The main objective is to support the [https://github.com/jamacias/turtle_playground](Turtleler playground).

## Features

* Laser: the turtles incorporate a simulated laser that published laser scans on every update. The simulated laser scans also have noise that is modelled as a normal distribution.
